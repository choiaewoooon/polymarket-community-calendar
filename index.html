이벤트 캘린더

7일 타임라인과 21일 오버뷰 그리드로 다가오는 예측 시장 이벤트를 한눈에 파악합니다. 시간대별 색상 코딩으로 마감 시점을 직관적으로 확인하세요.

Week Timeline + Grid
💰

99% 마켓 (Sure Bet)

확률 90% 이상의 고확률 마켓을 연환산 수익률 기준으로 정렬합니다. 안전도 등급(A/B/C)과 마감 카운트다운으로 리스크를 관리하세요.

Annualized Return Ranking
🇰🇷

한국 마켓

한국 관련 예측 시장만 모아서 보여줍니다. 한국어 번역과 함께 제공되어 별도 검색 없이 확인 가능합니다.

Korean Translation
⚡

라이브 트래커

날씨, 암호화폐, 금융 등 실시간 데이터와 예측 시장 확률을 비교합니다. 기상청 API 연동으로 날씨 마켓의 실제 결과를 추적합니다.
