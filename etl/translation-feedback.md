# 번역 피드백 로그

이 파일은 번역 에이전트가 번역 품질을 지속적으로 개선하기 위한 피드백 축적 저장소입니다.

---

## 사용 방법

번역 품질 이슈를 발견하면 아래 형식으로 기록합니다.
**10건 이상** 누적 시 번역 에이전트가 자동으로 `postprocess.py`와 `translation_prompt.md`를 업데이트합니다.

### 기록 형식

```markdown
### YYYY-MM-DD: [간단한 이슈 제목]
- **원문**: [영어 원문]
- **잘못된 번역**: [현재 번역 결과]
- **올바른 번역**: [수정된 번역]
- **원인**: [왜 잘못 번역되었는지]
- **조치**: [postprocess.py 규칙 추가 / translation_prompt.md 용어집 수정 / 기타]
- **반영 여부**: ⬜ 미반영 / ✅ 반영 완료
```
